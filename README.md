# Дизайн BurningHouse

Общий язык для всех сервисов на `burninghouse.ru`. Здесь решения и их причины —
не файлы стилей. Стили живут в самих сервисах; отсюда их копируют и сюда
возвращаются, когда нужно понять, почему сделано именно так.

## Идея в одном абзаце

Название читается не как пожар, а как **дом, в котором горит огонь**. Отсюда всё
остальное: ночь — это фон, тепло очага — единственное яркое пятно на странице,
а сервисы различаются тем, **чем в них топят**. Разные вещества горят разным
цветом: дерево янтарным, натрий золотым, стронций багровым, медь бирюзовым.
Знак у всех один и тот же, меняется только цвет пламени.

Побочная выгода: у фиолетовой палитры Material 3, на которой уже стоят
«Финансы», наконец появляется объяснение — это ночь вокруг дома, а не просто
выбранный когда-то оттенок.

Раскладывает по сервисам `node Shared/sync.mjs`.

## Как этим пользоваться

**Делаете новый сервис** — откройте [services.md](services.md), там чек-лист от
выбора вещества до фавикона.

**Правите существующий** — сверьтесь с [palette.md](palette.md) и
[motion.md](motion.md), чтобы не разъехаться с остальными.

**Спорите о вкусе** — почти у каждого решения здесь записана причина. Если
причина больше не действует, решение можно менять; если причина не записана,
значит это вкусовщина и её можно оспаривать свободно.

## Что ещё не решено

- Отображаемое название «Что смотрим» — моё предложение, не выбор. У поездок имя
  утверждено: «Куда поедем?», сервис работает на `trip.burninghouse.ru`.
- Поддомен для сервиса фильмов.
- Бирюза у поездок честна химически (медь так горит), но в ряду из четырёх
  выбивается из тёплой гаммы сильнее прочих — см. [palette.md](palette.md).
